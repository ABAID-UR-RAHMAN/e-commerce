EcoShop - Professional Multi-Vendor E-Commerce Platform

A production-ready, full-stack e-commerce system with buyer accounts, seller dashboards, invoicing, messaging, and notifications.

Features

  • ✅ Buyer Dashboard - Browse, search, and purchase products with secure checkout
  • ✅ Seller Dashboard - Publish products, track inventory, and manage orders
  • ✅ Invoicing System - Automatic invoice generation and payment tracking
  • ✅ Messaging Center - Direct buyer-seller communication
  • ✅ Real-Time Notifications - Order, payment, and message alerts
  • ✅ User Authentication - Secure signup/login with bcrypt and JWT
  • ✅ RESTful API Backend - Express.js with persistent data storage
  • ✅ Responsive UI - Modern, professional frontend with CSS Grid

Quick Start

Local Development

npm install
npm run start

Server runs on http://localhost:3000

Project Structure

ecoshop-ecommerce/
├── server.js                # Express backend (auth, products, invoices, messaging)
├── app.js                   # Frontend API client
├── styles.css               # Professional CSS design system
├── *.html                   # Pages (index, buyer, seller, marketplace, etc.)
├── package.json             # Dependencies
├── data/                    # JSON data stores
│   ├── accounts.json        # User accounts (email, hashed password, preferences)
│   ├── products.json        # Product listings
│   ├── invoices.json        # Order invoices
│   ├── messages.json        # Buyer-seller messages
│   └── notifications.json   # System notifications
└── .gitignore               # Git ignore rules

Environment Variables

PORT=3000                                    # Server port (default 3000)
JWT_SECRET=your-secret-key-change-in-prod   # JWT signing key

API Endpoints

  • POST /api/signup - Register a new account
  • POST /api/login - Authenticate user
  • POST /api/logout - Clear session
  • GET /api/products - List all products
  • POST /api/products - Create product (sellers only)
  • GET /api/messages - List user's messages
  • POST /api/messages - Send message
  • GET /api/invoices - List user's invoices
  • POST /api/checkout - Complete purchase and generate invoice
  • GET /api/me - Get current user info

Security Notes

  • Change JWT_SECRET in production.
  • Use environment variables, never hardcode secrets.
  • Replace JSON file storage with MongoDB/PostgreSQL for production.
  • Enable HTTPS in production.
  • Add rate limiting and CORS policies.
  • Implement email verification (SMTP integration provided as skeleton).

Next Steps (Production)
